# Waffle-Heaven-Website
This is a beautiful website for a dessert shop called Waffle Heaven. I built this using HTML, CSS, and Javascript for a college project to practice web design.<br>
<hr> 
🚀Features<br>
<b>Delicious UI</b>: A clean layout featuring mouth-watering waffle menus and food images.<br>
<b>Smart Navigation Bar</b>: When you click on "Menu" in top navigation bar, the page smoothly jumps straight down to the waffle menu section.<br>
<b>Customer Feedback Form</b>: A dedicated contact/order form placed at the bottom of the page.<br>
<b>Javascript Form Validation</b>: Smart Javascript code that checks if the user has filled out the form correctly before thhey submit it.<br>
<b>Hover Animations</b>: Smooth visual effects when you hover over buttons and food cards.<br>

💻Tech Stack<br>
<b>HTML5</b>: To build the structure, navigation links, texts, and form fields.<br>
<b>CSS3</b>: For custom colors, layouts, and the smooth scrolling navigation.<br>
<b>JavaScript</b>: To handle form validation logic.<br>

📁Files
<b>index.html</b>: The main website page.<br>
<b>style.css</b>: All the styling and layout code.<br>
<b>script.js</b>: The javascript code for form validation.<br>
<b>assets</b>: All the waffle images.<br>
